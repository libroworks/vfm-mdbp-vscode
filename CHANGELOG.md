## [0.4.0] - 2026-08-24

- Updated npm dependencies, with `@vivliostyle/vfm` tracking the latest release.
- Preserved code whitespace while adding InDesign paragraph separators to exported XML.
- Hardened `svgimg` path, parameter, image, and error handling.
- Added workspace-free and multi-root-aware conversion behavior.
- Unified command result messages and expanded regression tests.
